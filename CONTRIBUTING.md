# Contributing

Thanks for helping improve Awesome Free Developer Tools!

## What belongs here?

A tool must meet at least one of these conditions:

- It is open-source and can be used without purchasing a license.
- It offers a permanent free tier that provides meaningful functionality.
- It is a genuinely free service with no paid subscription required for the listed core use.

A free trial that expires is **not** eligible.

## Submission format

Add entries under the most relevant category using this format:

```markdown
- [Tool name](https://official.example/) — A short, original description. `Open source`
```

Use `Free tier` or `Free service` when appropriate instead of `Open source`.

## Before opening a pull request

- Check that the official link works.
- Check the current pricing page or license.
- Mention account requirements and important usage limits.
- Avoid duplicate entries.
- Write an original description.
- Do not copy paragraphs from another directory.
- If you are unsure whether a plan is still free, open an issue instead of guessing.

## Attribution

If you discovered a tool through another directory, you may mention that directory as a discovery source in your pull request. Do not copy its original descriptions or imply that it endorses this repository.
