# AI & Machine Learning

> AI services often change their free quotas. Entries marked `Free tier` should be checked against the provider's current usage limits and model availability.

- [Ollama](https://ollama.com/) — Runs supported language models locally on your own hardware. `Open source`
- [Open WebUI](https://openwebui.com/) — Self-hosted interface for interacting with local and remote AI models. `Open source`
- [llama.cpp](https://github.com/ggml-org/llama.cpp) — Runs supported language models efficiently on a range of hardware. `Open source`
- [Hugging Face Hub](https://huggingface.co/) — Hosts and shares machine-learning models, datasets, and demos; account and resource limits apply. `Free tier`
- [Google AI Studio](https://aistudio.google.com/) — Experiment with Google's generative AI models; API quotas and availability vary. `Free tier`
- [Open Interpreter](https://github.com/OpenInterpreter/open-interpreter) — Lets users operate local tools through natural-language commands; model/API costs may apply. `Open source`
- [Unsloth](https://unsloth.ai/) — Tools for fine-tuning and running language models. `Open source`
- [Deep Playground](https://playground.tensorflow.org/) — Interactive browser playground for neural networks. `Free service`
- [Netron](https://netron.app/) — Visualizes machine-learning model files. `Open source`
- [DeepSpeed](https://www.deepspeed.ai/) — Optimization library for large-scale deep-learning workloads. `Open source`
