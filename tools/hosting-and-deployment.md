# Hosting & Deployment

> Free hosting plans change frequently. Confirm quotas, acceptable-use rules, sleep behavior, bandwidth, and commercial-use terms before deploying.

- [GitHub Pages](https://pages.github.com/) — Hosts static websites directly from GitHub repositories. `Free service`
- [Cloudflare Pages](https://pages.cloudflare.com/) — Deploys static sites with a free plan and build limits. `Free tier`
- [Vercel](https://vercel.com/) — Frontend deployment platform with a free Hobby plan subject to eligibility and usage limits. `Free tier`
- [Netlify](https://www.netlify.com/) — Web deployment and hosting with a free plan and usage-based limits. `Free tier`
- [Codeberg Pages](https://codeberg.page/) — Static website hosting for Codeberg repositories. `Free service`
- [Neocities](https://neocities.org/) — Community-oriented static website hosting with a free plan. `Free tier`
- [Surge](https://surge.sh/) — Command-line publishing for static websites with a free option. `Free tier`
- [Cloudflare Workers](https://workers.cloudflare.com/) — Serverless application platform with a free usage allowance. `Free tier`
- [Val Town](https://www.val.town/) — Online environment for writing and sharing small server-side programs; free usage is limited. `Free tier`
- [Uptime Kuma](https://uptime.kuma.pet/) — Self-hosted uptime monitoring dashboard. `Open source`
- [Gatus](https://gatus.io/) — Self-hosted health-check and status monitoring tool. `Open source`
- [Coolify](https://coolify.io/) — Self-hostable platform for deploying applications and services. `Open source`
