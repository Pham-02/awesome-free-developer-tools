# Monitoring, Performance & Accessibility

- [Lighthouse](https://developer.chrome.com/docs/lighthouse/) — Audits page performance, accessibility, SEO, and best practices. `Open source`
- [PageSpeed Insights](https://pagespeed.web.dev/) — Measures page performance using Lighthouse and field data where available. `Free service`
- [WebPageTest](https://www.webpagetest.org/) — Tests website loading performance from different locations and browsers. `Free service` (public service limits apply)
- [GoatCounter](https://www.goatcounter.com/) — Privacy-friendly web analytics with hosted and self-hosted options. `Open source`
- [Umami](https://umami.is/) — Privacy-focused analytics that can be self-hosted. `Open source`
- [Plausible Community Edition](https://github.com/plausible/analytics) — Self-hostable web analytics software. `Open source`
- [Pa11y](https://pa11y.org/) — Command-line accessibility testing tools. `Open source`
- [Accessibility Insights](https://accessibilityinsights.io/) — Helps identify accessibility issues in websites and apps. `Free service`
- [WAVE](https://wave.webaim.org/) — Browser-based web accessibility evaluation. `Free service`
- [Responsively App](https://responsively.app/) — Open-source browser for testing responsive layouts across device views. `Open source`
- [Prometheus](https://prometheus.io/) — Collects and queries time-series metrics. `Open source`
- [Grafana](https://grafana.com/oss/grafana/) — Builds dashboards from metrics and logs. `Open source`
