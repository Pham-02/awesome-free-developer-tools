# Security & Networking

> Use security tools only on systems you own or are explicitly authorized to test.

- [OWASP ZAP](https://www.zaproxy.org/) — Web application security scanner for authorized testing. `Open source`
- [Nmap](https://nmap.org/) — Network discovery and security auditing utility. `Open source`
- [Wireshark](https://www.wireshark.org/) — Network protocol analyzer. `Open source`
- [Zeek](https://zeek.org/) — Network security monitoring framework. `Open source`
- [Sniffnet](https://sniffnet.net/) — Network traffic monitoring application. `Open source`
- [osquery](https://osquery.io/) — Uses SQL-like queries to inspect operating-system state. `Open source`
- [Wazuh](https://wazuh.com/) — Security monitoring and threat detection platform. `Open source`
- [Greenbone Community Edition](https://greenbone.github.io/docs/) — Vulnerability management tools for authorized environments. `Open source`
- [Grype](https://github.com/anchore/grype) — Scans container images and filesystems for known vulnerabilities. `Open source`
- [Nuclei](https://github.com/projectdiscovery/nuclei) — Template-based vulnerability scanner for authorized testing. `Open source`
- [Web Check](https://web-check.xyz/) — Inspects public information and configuration details about websites. `Open source`
- [DNSDumpster](https://dnsdumpster.com/) — DNS reconnaissance service; use within its terms and limits. `Free service`
- [Have I Been Pwned](https://haveibeenpwned.com/) — Checks whether an email address appears in known data breaches. `Free service`
