# Game Development

- [Godot Engine](https://godotengine.org/) — Open-source engine for making 2D and 3D games. `Open source`
- [GDevelop](https://gdevelop.io/) — Open-source, no-code game engine with optional hosted services. `Open source`
- [pygame-ce](https://pyga.me/) — Community edition of the Python game development library. `Open source`
- [LÖVE](https://love2d.org/) — Framework for making 2D games in Lua. `Open source`
- [Defold](https://defold.com/) — Game engine for 2D and 3D projects. `Free service` (check current license and terms)
- [Ren'Py](https://www.renpy.org/) — Engine for visual novels and story-driven games. `Open source`
- [Tiled](https://www.mapeditor.org/) — General-purpose tile map editor. `Open source`
- [LDtk](https://ldtk.io/) — 2D level editor for tile-based game worlds. `Open source`
- [Kenney Assets](https://kenney.nl/assets) — Collection of game assets released under permissive terms; check each asset's license. `Free service`
- [OpenGameArt](https://opengameart.org/) — Community library of game art and audio with asset-specific licenses. `Free service`
- [RenderDoc](https://renderdoc.org/) — Graphics debugger for frame capture and inspection. `Open source`
- [Tracy Profiler](https://github.com/wolfpld/tracy) — Profiler for analyzing application performance. `Open source`
