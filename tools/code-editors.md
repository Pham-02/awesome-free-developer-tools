# Code Editors & IDEs

- [VSCodium](https://vscodium.com/) — Community-built distribution of Visual Studio Code without Microsoft's branding and telemetry defaults. `Open source`
- [Visual Studio Code](https://code.visualstudio.com/) — Source-code editor with debugging, extensions, and language tooling. `Free service` (proprietary; check license/terms)
- [Neovim](https://neovim.io/) — Extensible, terminal-focused text editor. `Open source`
- [Emacs](https://www.gnu.org/software/emacs/) — Customizable editor and extensible computing environment. `Open source`
- [Lite XL](https://lite-xl.com/) — Lightweight, extensible code editor. `Open source`
- [Geany](https://www.geany.org/) — Fast, lightweight IDE with support for many programming languages. `Open source`
- [Helix](https://helix-editor.com/) — Modal text editor with built-in language-server support. `Open source`
- [Apache NetBeans](https://netbeans.apache.org/) — IDE for Java and other languages. `Open source`
- [KDevelop](https://www.kdevelop.org/) — IDE for C, C++, Python, and other languages. `Open source`
- [Thonny](https://thonny.org/) — Beginner-friendly Python IDE. `Open source`
- [Zed](https://zed.dev/) — High-performance code editor; check current platform and feature availability. `Free service` (verify current terms)
- [Acode](https://acode.app/) — Code editor for Android devices; check optional paid features. `Free tier`
- [Squircle CE](https://github.com/massivemadness/Squircle-CE) — Open-source code editor for Android. `Open source`
