# Code Quality, Formatting & Analysis

- [Prettier](https://prettier.io/) — Opinionated formatter for JavaScript, CSS, HTML, and more. `Open source`
- [Biome](https://biomejs.dev/) — Formatter and linter for web development projects. `Open source`
- [EditorConfig](https://editorconfig.org/) — Keeps basic coding style settings consistent across editors. `Open source`
- [Tokei](https://github.com/XAMPPRocky/tokei) — Reports code statistics by language. `Open source`
- [ripgrep](https://github.com/BurntSushi/ripgrep) — Fast recursive text search for source trees. `Open source`
- [Difftastic](https://github.com/Wilfred/difftastic) — Structural diff tool that understands programming syntax. `Open source`
- [Delta](https://github.com/dandavison/delta) — Syntax-highlighted pager for Git diffs. `Open source`
- [WinMerge](https://winmerge.org/) — Visual comparison and merging for files and folders. `Open source`
- [SVGO](https://github.com/svg/svgo) — Optimizes SVG files. `Open source`
- [Shiki](https://shiki.style/) — Syntax highlighter based on TextMate grammars. `Open source`
- [Lighthouse](https://github.com/GoogleChrome/lighthouse) — Audits web pages for performance, accessibility, and best practices. `Open source`
- [PHPStan](https://phpstan.org/) — Static analysis for PHP code. `Open source`
- [ty](https://github.com/astral-sh/ty) — Fast Python type checker. `Open source`
