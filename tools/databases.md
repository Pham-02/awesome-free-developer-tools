# Databases & Data

- [SQLite](https://sqlite.org/) — Lightweight embedded relational database. `Public domain`
- [DB Browser for SQLite](https://sqlitebrowser.org/) — Visual interface for creating and inspecting SQLite databases. `Open source`
- [DuckDB](https://duckdb.org/) — Analytical database designed for fast local data workflows. `Open source`
- [DBeaver Community](https://dbeaver.io/) — Universal database client for many database engines. `Open source`
- [Beekeeper Studio Community](https://www.beekeeperstudio.io/) — Friendly database GUI with a community edition. `Open source`
- [Baserow](https://baserow.io/) — Open-source no-code database that can be self-hosted; hosted plan limits may apply. `Open source`
- [NocoDB](https://nocodb.com/) — Turns databases into a spreadsheet-style interface. `Open source`
- [Grafana](https://grafana.com/oss/grafana/) — Dashboards and visualization for metrics and logs. `Open source`
- [Qdrant](https://qdrant.tech/) — Vector database for similarity search and AI applications. `Open source`
- [Meilisearch](https://www.meilisearch.com/) — Search engine that can be self-hosted. `Open source`
- [ChartDB](https://chartdb.io/) — Database schema visualization tool. `Open source`
- [Prometheus](https://prometheus.io/) — Monitoring and alerting toolkit with a time-series database. `Open source`
