# Containers & Command Line

- [Docker Engine](https://docs.docker.com/engine/) — Container runtime for building and running applications. `Open source` (Docker Desktop has separate terms)
- [Podman](https://podman.io/) — Daemonless container engine. `Open source`
- [Docker Compose](https://docs.docker.com/compose/) — Defines and runs multi-container applications. `Open source`
- [Portainer CE](https://www.portainer.io/) — Web interface for managing container environments; check edition licensing. `Open source`
- [Lazydocker](https://github.com/jesseduffield/lazydocker) — Terminal UI for Docker and Docker Compose. `Open source`
- [Dozzle](https://dozzle.dev/) — Browser-based viewer for container logs. `Open source`
- [Dive](https://github.com/wagoodman/dive) — Inspects and analyzes Docker image layers. `Open source`
- [Dockle](https://github.com/goodwithtech/dockle) — Linter for container images and security best practices. `Open source`
- [ripgrep](https://github.com/BurntSushi/ripgrep) — Fast command-line search tool. `Open source`
- [bat](https://github.com/sharkdp/bat) — `cat` replacement with syntax highlighting and Git integration. `Open source`
- [zoxide](https://github.com/ajeetdsouza/zoxide) — Smarter directory-jumping command for the shell. `Open source`
- [Atuin](https://atuin.sh/) — Searchable shell history; local features are free and sync options may differ. `Open source`
- [Oh My Posh](https://ohmyposh.dev/) — Customizable command prompt theme engine. `Open source`
- [VisiData](https://www.visidata.org/) — Interactive terminal tool for exploring tabular data. `Open source`
- [VHS](https://github.com/charmbracelet/vhs) — Creates terminal recordings from scripted commands. `Open source`
