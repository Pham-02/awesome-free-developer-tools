# API Development & Testing

- [Hoppscotch](https://hoppscotch.io/) — Open-source API development and testing workspace. `Open source`
- [Bruno](https://www.usebruno.com/) — Git-friendly API client with collections stored as files. `Open source`
- [HTTPie](https://httpie.io/) — Human-friendly HTTP client available as a CLI and desktop app; check product-specific terms. `Open source`
- [FastAPI](https://fastapi.tiangolo.com/) — Python framework for building APIs with type hints. `Open source`
- [ReDoc](https://github.com/Redocly/redoc) — Generates interactive API documentation from OpenAPI definitions. `Open source`
- [JSONPlaceholder](https://jsonplaceholder.typicode.com/) — Fake REST API for prototypes and tutorials. `Free service`
- [Beeceptor](https://beeceptor.com/) — Mock API endpoints and inspect requests; free plan has limits. `Free tier`
- [Insomnia](https://insomnia.rest/) — API client with a free offering; verify current plan limits. `Free tier`
- [Yaak](https://yaak.app/) — API client for working with HTTP, GraphQL, and other protocols. `Free service` (verify current terms)
- [Mockoon](https://mockoon.com/) — Create and run mock APIs locally. `Open source`
- [WireMock](https://wiremock.org/) — HTTP API simulation and service virtualization. `Open source`
- [Pipedream](https://pipedream.com/) — Connect APIs and automate workflows; free plan is usage-limited. `Free tier`
