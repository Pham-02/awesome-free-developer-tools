# Git, GitHub & Collaboration

- [Git](https://git-scm.com/) — Distributed version control system. `Open source`
- [GitHub CLI](https://cli.github.com/) — Work with GitHub repositories and workflows from a terminal. `Open source`
- [GitHub Desktop](https://desktop.github.com/) — Desktop interface for Git and GitHub. `Open source`
- [Forgejo](https://forgejo.org/) — Self-hosted software forge for collaborative development. `Open source`
- [Gitea](https://about.gitea.com/) — Lightweight self-hosted Git service. `Open source`
- [GitLab](https://about.gitlab.com/) — Git repository hosting with a free plan; limits and features vary. `Free tier`
- [Codeberg](https://codeberg.org/) — Community-run hosting for free and open-source projects. `Free service`
- [lazygit](https://github.com/jesseduffield/lazygit) — Terminal UI for common Git operations. `Open source`
- [gitui](https://github.com/extrawurst/gitui) — Fast terminal interface for Git. `Open source`
- [pre-commit](https://pre-commit.com/) — Framework for managing Git pre-commit hooks. `Open source`
- [commitlint](https://commitlint.js.org/) — Checks commit messages against configurable conventions. `Open source`
- [act](https://github.com/nektos/act) — Runs many GitHub Actions workflows locally using Docker. `Open source`
- [Star History](https://star-history.com/) — Visualizes GitHub repository star growth. `Free service`
- [Open VSX](https://open-vsx.org/) — Vendor-neutral registry for editor extensions. `Free service`
