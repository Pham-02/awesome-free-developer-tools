## ✨ What's inside?

A hand-curated directory of free and open-source developer tools, organized by what you need to do. Entries link to their official project or provider pages and use short, independently written descriptions.

- **Free and open source:** tools you can use without buying a license.
- **Useful free tiers:** hosted services with an ongoing free plan, clearly labeled.
- **Organized by task:** separate files make browsing and contributions easier.
- **Maintained with automation:** scheduled link checks and monthly review reminders.

> [!IMPORTANT]
> A free plan is not necessarily unlimited. Providers can change pricing, quotas, eligibility, and licenses at any time. Always check the official terms before depending on a tool.

## 🏷️ How entries are labeled

| Label | Meaning |
|---|---|
| `Open source` | Source code is available under an open-source license, or the project uses a public-domain dedication. Check the linked license. |
| `Free tier` | The provider offers an ongoing free plan with limits or eligibility requirements. |
| `Free service` | The listed core service is available without a paid subscription. |

### What counts as free?

**Included**
- Open-source software that can be used without purchasing a license.
- Services with a permanent, usable free tier.
- Free services that do not require a paid subscription for their listed core functionality.

**Excluded**
- Time-limited trials with no ongoing free option.
- Paid-only products.
- Listings whose free status cannot be reasonably established.
- Duplicate directory pages that simply point to other collections.

## 🤖 Repository maintenance

This repository includes lightweight automation to help keep the directory useful:

- **Link checks:** GitHub Actions checks Markdown links on pushes, pull requests, and a weekly schedule.
- **Monthly review reminder:** an automated issue prompts contributors to re-check free plans, quotas, and licenses.
- **Submission template:** contributors can suggest a tool using a structured GitHub issue form.

See [MAINTENANCE.md](MAINTENANCE.md) for setup and troubleshooting details. Automated link checks only test reachability; they do **not** verify that a service is still free.

## 🤝 Contributing

Found a useful free developer tool? Contributions are welcome!

1. Read the [contribution guidelines](CONTRIBUTING.md).
2. Confirm the tool has a permanent free option or an appropriate open-source license.
3. Link to the official website, documentation, pricing page, or repository.
4. Write a concise description in your own words.
5. Mention meaningful limits, account requirements, and commercial-use restrictions.
6. Open a pull request or [submit a tool for review](../../issues/new?template=tool-review.yml).

Please don't submit trial-only or paid-only products. When free status is unclear, open an issue for review rather than guessing.
