# Awesome Free Developer Tools

A community-curated collection of developer tools that can be used for free.

> **Scope:** Free and open-source software, permanently free services, and services with a usable free tier. Time-limited trials and paid-only products are excluded.
>
> **Important:** Free plans change. Check each provider's current pricing, usage limits, license, and terms before relying on a tool. This is an initial curated selection, not a claim that every FMHY listing has been independently audited.

## Inclusion labels

| Label | Meaning |
|---|---|
| `Open source` | Source code is publicly available under an open-source license; check the project license. |
| `Free tier` | The provider offers an ongoing free plan with limits. |
| `Free service` | The listed core service is offered without a paid subscription. |

A free tier is not the same as unlimited use. Sign-up, usage caps, attribution requirements, and commercial-use restrictions may apply.

## Contributing

Contributions are welcome! Before submitting a tool:

1. Confirm that it has a usable free option today.
2. Link to the official product or project page.
3. Include the license for open-source projects where possible.
4. Describe meaningful limits (account required, usage caps, self-hosting, etc.).
5. Do not submit time-limited trials or paid-only products.
6. Use your own short description; do not copy descriptions from other directories.

See [CONTRIBUTING.md](CONTRIBUTING.md).
