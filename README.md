## 📌 About

Finding useful developer tools can be difficult, especially when many services require expensive subscriptions.

This repository aims to make that easier by collecting **free developer tools, open-source projects, and services with useful free plans** in one place.

Whether you're a beginner, student, hobbyist, or professional developer, you'll find resources to help you build projects more efficiently.

## 🏷️ Legend

| Label | Meaning |
|---|---|
| 🟢 Free | Free to use without a paid subscription |
| 🔓 Open Source | Source code is publicly available |
| ☁️ Free Tier | Offers a limited free plan |
| 🖥️ Self-Hosted | Can be installed and hosted yourself |

*Free plans may have usage limits. Always check the official pricing and license pages.*

## 🤝 Contributing

Contributions are welcome! Help make this collection more useful for developers.

Before submitting a contribution, please make sure:

- The tool is genuinely free, open-source, or offers a usable free tier.
- The official website is included.
- The tool is relevant to developers.
- The description is short and accurate.
- The tool is listed in the correct category.
- The entry is not already included.

### How to contribute

1. Fork this repository.
2. Add your tool to the appropriate category.
3. Follow the existing table format.
4. Submit a pull request.

Suggested format:

| Tool | Description | Type |
|---|---|---|
| [Tool Name](https://example.com/) | Brief description of the tool | 🔓 Open Source |
